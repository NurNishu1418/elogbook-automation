What this app does

A local tool for the BCPS e-Logbook portal: choose an Excel workbook of logbook entries, validate it locally, and (only when you choose to) create real drafts on the portal - never final-submitted.

Safety rules (always enforced)

  • Save as Draft only. There is no Final Submit button anywhere in this app.
  • Never Approve, Forward, Complete, or Delete anything on the portal.
  • Every row is checked against existing portal drafts before creating a new one - duplicates are skipped.
  • Every saved draft is re-read from the portal and field-checked before being marked successful.
  • Only one upload job runs at a time.
  • If something looks systemic (repeated consecutive failures, CAPTCHA, OTP, account lock, or an outage), the run stops automatically instead of continuing blindly.

Credentials

Your username and password are used only in memory for this session, to log in to the portal and to launch the upload process. They are never written to any file, never included in logs, and never appear in Excel output or screenshots. A .env file may still exist in the project folder as a fallback for command-line/development use only - it is not required to use this app.
